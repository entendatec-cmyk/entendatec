# Entenda Tec — Histórico de versões

## 1.0.3 — 01/10/2026

- Melhorado o botão de copiar o Prompt Mestre.
- Impedida a cópia do texto inicial antes da geração do prompt.
- Adicionado tratamento de erro caso a cópia para a área de transferência falhe.
- Mantidas as funcionalidades existentes da versão 1.0.2.

## 1.0.2 — 01/10/2026

- Corrigida a associação da janela ao aplicativo no Linux.
- Adicionado `desktopName`.
- Ativado `syncDesktopName`.
- Mantidas as funcionalidades existentes da versão 1.0.1.

## 1.0.1 — 01/10/2026

- Adicionado ícone personalizado do aplicativo.
- Adicionado controle de versão.
- Versão exibida na tela de ajuda.
- Versão obtida automaticamente pelo Electron a partir do `package.json`.

## 1.0.0 — Versão inicial

- Primeira versão funcional do Entenda Tec.
- Geração do Prompt Mestre.
- Autosave.
- Recuperação de rascunho.
- Limpeza do formulário e do rascunho salvo.
- Exportação para TXT.
- Exportação para HTML.
- Tela de ajuda.
